# 系统标识

Ubuntu、Debian、Arch Linux、Fedora、CentOS、Rocky Linux、AlmaLinux、Alpine Linux、Linux 和 Apple 的 SVG 路径来自 [Simple Icons](https://github.com/simple-icons/simple-icons/tree/develop/icons)，获取日期 2026-09-19。Simple Icons 图标集以 [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md) 提供；各系统名称和标识的商标权属于其原权利人，仅用于识别设备的操作系统。

Windows 标识由四个蓝色方块组成，在项目内用 SVG 绘制。所有图标随应用打包，不在运行时向第三方请求资源。
