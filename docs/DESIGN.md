# Your devices, your space.

Nexus 0.2 的首页是设备空间。设备首先以一个可以拿起、移动、放下的对象出现。默认内容只有系统图标、名称和细小的状态点；监控信息和操作集中在交互后打开的浮动面板中。

## 视觉和交互

画布铺满整个窗口，保留大面积留白。系统标题栏与应用顶端融合；主工具以底部悬浮程序坞呈现。查找与筛选只有主动打开后出现，外观设置与探针配置通过临时浮层进入。

设备没有常驻卡片底板和指标条，选择或悬停时才出现轻微轮廓。不同系统以各自标识呈现，尺寸可调。背景用本地 CSS 曲面和渐变形成轻微层次，避免把界面变成密集监控仪表盘。

拖动设备修改世界坐标；拖动空白修改相机偏移；围绕鼠标缩放保留指针所指的世界位置。平移、缩放都不改动设备布局。设备位置由 SQLite 保存，相机和外观由当前应用的本地存储保存。

用户自己的布局在升级后保留，新导入设备使用较松散的默认位置。重新排列必须由用户点击「舒展排列」；不在刷新监控数据或重新打开应用时自动排序。

## 当前边界

全屏是应用提供的沉浸模式，不接管 Windows 桌面或壁纸层。首页以设备图标为主，监控、连接和文件操作放在设备详情中；标签用于查找设备。

后台的设备模型、探针、SSH/SFTP、凭据和远程操作继续由现有主进程模块提供。所有新的窗口能力依然通过明确列出的 preload API 与 IPC 进入，不开放任意主进程调用。
