## 验证边界

第三方 Docker、宝塔和 3x-ui 安装器没有在用户的生产服务器上执行。测试服务端的环境与安装结果是受控 fixture，不等于各 Linux 发行版的实际安装结果。

Windows / macOS / NAS 的快捷命令和能力限制有自动测试，但没有在所有目标设备上实测。探针服务启动检查不验证服务端分组认证，需在实际状态页核对。

程序未签名。安装中断不回滚服务器改动，文件重试不是断点续传，任务队列不跨应用重启保存。
