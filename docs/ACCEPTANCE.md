## 测试覆盖

0.3.0 新增验证：通过本机真实 SSH 协议执行自动识别，关联进程目录、PID 与端口，解析 Docker Compose 标签，区分确认项和项目线索；单项权限不足、所有来源失败、采集上限和格式异常均有明确反馈。验证并发扫描复用、缓存到期、手动刷新和更改连接后失效；验证命令超时与输出超限后仍可执行后续命令，以及中文跨数据块解码。POSIX 采集脚本通过本机 Git Bash 配合模拟系统命令实际执行，检查返回状态、数量上限及 cron 参数和环境变量值排除。

新增桌面流程验证保存 SSH 后自动扫描、分类搜索、缓存复用、刷新失败保留上次结果及恢复。关键表单、详情、项目与设置文字验证至少 15px 和 4.5:1 对比度；截图检查详情、设置与识别结果布局。

0.2.1 桌面流程额外验证中国、日本、香港所在地角标，以及手动设置设备所在地。设备名称和面板字号放大后，重新验证添加、编辑、详情与桌面操作流程。当前真实探针所在地代码为 `cn`、`jp`、`hk`，均有内置旗帜。

核心测试覆盖探针稳定 ID、单位、缺失指标、时间戳与过期处理；重启必须观察离线再上线的状态转换；SSH 参数注入防护；设备与加密凭据的 SQLite 保存、读取、删除。

新增画布与系统识别验证：缩放围绕鼠标保持世界锚点不变；负坐标和超出旧边界的设备可保存与定位；系统标识根据类型和探针识别。桌面测试额外验证平移和缩放不改变设备坐标、浮动面板、隐藏程序坞可召回、F11 进出全屏，以及应用重启后恢复负坐标布局、相机和背景。

Windows 原生全屏事件经验证会先于 `isFullScreen()` 状态更新触发，现按进入 / 离开事件的语义同步前端，已通过实际 Electron 窗口的进出全屏回归。

SSH/SFTP 测试在本机回环地址启动真实 ssh2 协议服务端，验证主机指纹、错误密码、命令成功 / 错误退出码、目录浏览、文件上传与下载内容一致、新建 / 重命名 / 删除目录和文件、缺失路径及操作超时。

桌面测试覆盖添加、编辑、画布拖动并持久化、关闭应用后恢复、删除设备；切换探针接口、导入 6 个测试节点、搜索、指标展示、SFTP 未配置地址时的错误反馈，以及接口 HTTP 503 后显示状态未知。测试使用隔离临时用户目录，不污染真实设备配置。

发现并修复了切换探针接口时复用旧请求的竞态：现在中止旧请求，并让等待旧请求的调用读取新配置对应的结果。
