# 架构

```text
React / TypeScript
  设备画布、监控、运行内容、终端、文件、部署面板
                 │ NexusAPI
Electron sandbox preload / contextBridge
                 │ 主 frame 校验与 IPC 参数校验
Electron main
  ├─ Store → sql.js / SQLite
  ├─ safeStorage → 本机凭据加密
  ├─ fetchProbe → ServerStatus JSON
  ├─ Sessions → ssh2 PTY / xterm.js
  ├─ Deployments → 环境检查 / 脚本确认 / 安装验证
  └─ Transfers → SFTP 队列 / 目录传输 / 临时文件
```

## 存储与连接

设备、坐标、设置和主机信任记录保存在 SQLite。敏感值单独加密，系统加密不可用时拒绝保存。Linux 的 basic_text 后端不用于保存凭据。数据库写入使用临时文件替换。

SSH、SFTP、识别和部署共用认证与主机指纹检查，不提供忽略密钥验证的入口。系统终端启动接口保留，但设备详情默认使用内置终端。

渲染进程没有 Node 权限，通过窄接口调用主进程；主进程检查调用 frame 和参数。应用不允许打开新窗口、跳转到外部页面或自动授权权限。

## 终端

每个会话独立连接，最多同时运行 12 个。SSH PTY 尺寸跟随终端调整。输出按 64 KB 分块，渲染确认积压时暂停读取；每个会话只保留约 1 MB 历史。收起窗口后保留连接，重开时恢复有限输出；退出应用关闭连接。

xterm.js 按需加载，不处理终端超链接点击，不把远程终端输出持久化为日志。远端可以主动输出敏感内容，不能将隐藏输入保证扩大为对所有第三方输出的保证。

终端复制粘贴使用受限的剪贴板 IPC，粘贴交给 xterm 的 paste 接口处理 bracketed paste，输入继续受队列和分块限制。SearchAddon 搜索当前输出。主窗口默认隐藏到托盘，后台不限制渲染节流，保留流控确认和监控刷新；完全退出时清理连接，活动任务需要确认。

## 部署

安装来源由主进程固定，渲染进程不能传入任意安装命令。预检查系统、发行版、架构、权限、依赖和现有安装；脚本大小限制为 1 MB，确认计划保留 5 分钟。开始安装前再次检查环境。

安装使用已经预览的脚本，上传到私有临时目录后通过 PTY 执行。sudo 与组密码由远端终端交互处理。安装和验证在同一权限环境运行，退出码不明或验证失败不视为成功。中断没有回滚语义。

Linux VPS 与服务器使用相同设备策略。3x-ui 的入口脚本和安装参数均固定 v3.9.0，检查已有 x-ui 文件、服务和数据，完成后验证二进制与 systemd 服务。

## 文件传输

队列在主进程中管理，最多保留 100 个任务、同时执行 2 个，同一设备串行传输。任务绑定创建时的连接配置，地址变化后不会自动改投另一台服务器。单项上限为 100 GB、10000 个目录或文件、64 层目录。取消关闭连接，重试从头开始，应用重启后不恢复任务。

传输不跟随符号链接，不复制特殊文件；Windows 下载拒绝保留名称、非法字符、大小写冲突和路径穿越。使用目标目录内的临时项，传输完成后再提交。已有目标先询问跳过、覆盖 / 合并或保留两份；同类选择可在当前任务内复用，重试后重新询问。

覆盖前再次核对目标的类型、大小、时间和权限。SFTP 覆盖先将原文件移动到独立备份，提交失败尝试恢复；恢复或清理失败会报告备份位置。取消等待冲突选择不会写入目标；文件提交期间先完成提交或恢复，再关闭连接。同名目录按项目合并，保留目标独有内容，已经提交的项目不作整体回滚。失败时尝试清理自己创建的临时项，断线时可能保留远端临时文件。

只复制内容，不保留 ACL、扩展属性或属主，文件使用受限权限。并发修改中的源文件不保证得到一致快照。

## 监控与识别

ServerStatus JSON 请求限制 5 MB，超时 12 秒，不跟随重定向；缺失指标显示未知，接口故障不保留旧值冒充实时状态。节点使用稳定 ID 绑定，客户端组密码与桌面接口 Token 分开。

Linux 运行识别执行固定只读命令，以来源标注权限不足、工具缺失和采集上限。进程目录、容器标签、服务与端口提供证据，无法确认的内容保留为线索。缓存按设备和连接区分，手动刷新重新采集。

## 测试

核心测试使用 Node test runner，桌面测试使用 Playwright 和隔离 Electron 数据目录。本机 ssh2 服务端提供真实协议连接，受控安装 fixture 不执行第三方安装器。Windows 打包测试检查 asar 与当前构建一致，并排除私有研究文件。
